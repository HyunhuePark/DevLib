## DevLib는 개발자로서 실무를 경험으로 제작된 C/C++ 기반의 라이브러리입니다.
 개발 시 반복적으로 요구되는 기능들을 모듈화하고 클래스 라이브러리 형태로 설계되었습니다.
이 라이브러리 핵심 목표는 개발 생산성 향상, 코드의 재사용성 증애, 그리고 반복적이고 복잡한 로직의 표준화에 있습니다. 각 기능은 독립적인 Class로 분리되어 있습니다.

## 구조
* **DevLib**는 기능별로 디렉토리를 분리하여 설계하였습니다.
```
/DevLib
|
├─/3rd ( 외부 라이브러리 )
|
├─/Base ( 필수 구성요소 )
|
├─/GL ( OpenGL 객체 )
|
├─/GUI ( Window 도구 )
|
├─/Graphics ( Image 처리 도구 )
|
├─/IO ( File, Socket, Serial 도구 )
|
├─/MultiMedia ( FFmpeg 기반 Enc/Dec, USB 카메라, RTSP 서버/클라이언트 )
|
├─/Routine ( Tile지도, Message 통신, 확장 도구 ) 
|
├─/Utility ( Config, 문자열 등 도구 모음 )
|
└─/Visualization ( 2D/3D 가시화 도구 )

```

## 활용 방안

* 개발 시간 단축: 검증된 모듈을 재사용하여 프로젝트 초기 단계의 개발 속도를 크게 향상시킬 수 있습니다.

* 품질 표준화: 여러 프로젝트에 일관된 방식의 코드를 적용하여 코드의 품질을 높이고 유지보수를 용이하게 합니다.

* 핵심 로직 집중: 인프라 수준의 코드(파일 I/O, 로깅, 보안 등) 작성에 드는 노력을 줄이고, 비즈니스 로직 구현에 더 집중할 수 있습니다.
